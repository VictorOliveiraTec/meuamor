# Nossa História — versão para GitHub Pages

Esta pasta é uma versão estática do site. Ela usa apenas HTML, CSS, JavaScript e a foto em `assets/primeira-foto.webp`.

## Publicar no GitHub

Crie um repositório no GitHub e envie todos os arquivos desta pasta, mantendo esta estrutura:

```text
index.html
styles.css
script.js
assets/primeira-foto.webp
```

Depois, no GitHub, abra **Settings → Pages**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)`. Salve e aguarde a URL do site aparecer.

Não é necessário instalar Node.js, React ou Vite para esta versão.

## Editar o conteúdo

Abra `script.js` e altere os textos dentro de `const moments`. Para adicionar outra foto, coloque o arquivo em `assets/` e informe o caminho no campo `image`, por exemplo `assets/minha-foto.webp`.
